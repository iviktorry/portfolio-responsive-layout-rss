## 🛠 My Process

### Built With

- Semantic HTML5 markup
- CSS Custom Properties (Variables), Flexbox, CSS Grid
- Vanilla JavaScript
- **Vite** — Frontend Build Tool

### 🧠 What I Learned

In this project, I experimented with several new techniques and workflows:

- **CSS Modularization:** For the first time, I split my CSS into logical modules (global styles, variables, components) and imported them into a main stylesheet instead of writing one massive file. This made the codebase much cleaner and easier to maintain.
- **Mouse-tracked Interactive Slider:** I implemented a custom horizontal scroll in the portfolio section where the content moves left or right depending on which side of the viewport the user hovers over.
  > **Note:** I used AI assistance to write the event listener logic for this feature. To be fully transparent, I haven't completely mastered the coordinate math on my own yet, but integrating this code was a great hands-on lesson in handling complex JS interactions.

### 🔄 What I Reinforced

Beyond learning new concepts, this project helped me sharpen my existing core skills:

- **Building with Vite:** Practical experience using a modern, fast build tool rather than relying solely on Live Server.
- **DOM Manipulation via JavaScript:** Strengthened my skills in interacting with page elements (toggling classes, managing modals, and controlling accordion behavior).
- **Full Landing Page Development:** Built a complete single-page website from header to footer, maintaining a clean structure and cohesive design.
